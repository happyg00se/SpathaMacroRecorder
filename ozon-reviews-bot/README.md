# Бот ответов на отзывы и вопросы Ozon

Сам забирает новые отзывы и вопросы из магазина на Ozon, отдаёт их **локальной нейросети на твоём компьютере**
(Ollama / LM Studio — ни одного платного токена), публикует ответы обратно в Ozon и отчитывается в Telegram.

Нейросеть смотрит на **смысл текста, а не на звёзды**: «пятёрка» с жалобой на качество получает извинение
и приглашение в чат, «тройка» с похвалой — благодарность.

```
Ozon (API или Chrome) ──► локальная нейросеть ──► ответ в Ozon
                                   │
                                   └──► Telegram: отчёт или кнопки ✅ 🔄 ✏️ ⏭
```

## Что умеет

- Проверяет отзывы и вопросы каждые N минут (по умолчанию 15) и по команде `/check`.
- Определяет тон (🟢/🟡/🔴) и тему: размер, качество, доставка, «не подошло», вопрос о товаре…
- Три режима публикации, переключаются прямо из Telegram:
  - `/mode_all` — всё публикуется само, тебе приходит отчёт;
  - `/mode_safe` — позитив публикуется сам, негатив и сложные случаи приходят на кнопки (по умолчанию);
  - `/mode_manual` — ничего без твоей кнопки.
- Кнопки под каждым ответом: **✅ Опубликовать**, **🔄 Переписать**, **✏️ Свой текст** (или указание нейросети
  через `?`, например `? предложи прислать фото брака`), **⏭ Пропустить**.
- Сам зовёт тебя, если: угрозы, суд, риск для здоровья, подделка, спор о деньгах или нейросеть не уверена.
- Страхует от штрафов Ozon: ответ со ссылкой, телефоном, почтой или мессенджером никогда не уходит сам.
- Помнит, что уже обработал (SQLite в `data/`), — после перезапуска ничего не дублирует.

## Два способа достать отзывы

| | `source: api` | `source: browser` |
|---|---|---|
| Как | Ozon Seller API | Бот сам открывает кабинет seller.ozon.ru в Chrome |
| Нужно | Client-Id и Api-Key, **подписка Premium Plus / Pro** (без неё Ozon не отдаёт отзывы в API) | Один раз войти в кабинет через `login.bat` |
| Надёжность | Высокая | Зависит от вёрстки кабинета: Ozon её меняет, тогда поправь селекторы (см. ниже) |

Если Premium Plus есть — бери `api`. Нет — `browser`.

## Установка (Windows)

1. **Python 3.10+** с [python.org](https://www.python.org/downloads/) — при установке отметь «Add python.exe to PATH».
2. **Ollama** с [ollama.com](https://ollama.com/download), затем в командной строке:
   ```
   ollama pull qwen2.5:14b
   ```
   Модель под видеокарту:
   - 8 ГБ видеопамяти — `qwen2.5:7b`;
   - 12–16 ГБ — `qwen2.5:14b`;
   - 24 ГБ и больше — `qwen2.5:32b`.

   Русский у Qwen хороший. LM Studio тоже подходит: включи в нём сервер и укажи `base_url: http://localhost:1234/v1`.
3. **Telegram-бот**: напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
4. Запусти **`setup.bat`**: он поставит всё нужное и откроет `config.yaml`. Заполни:
   - `source` и ключи Ozon (для `api`);
   - `telegram.token`;
   - раздел `shop` — название, о чём магазин, подпись;
   - `examples` — 3–10 реальных отзывов с идеальными ответами. **Это главное для качества ответов**: нейросеть копирует твой стиль.
5. Узнай свой chat id: запусти `run.bat`, напиши боту `/start` — он пришлёт число. Впиши его в `telegram.allowed_chat_ids` и перезапусти.
6. Для `source: browser` — запусти `login.bat` и войди в кабинет Ozon в открывшемся окне (вход сохранится).
7. **`dry-run.bat`** — покажет, что бот ответил бы на текущие отзывы, ничего не публикуя. Посмотри и поправь `style_rules` / `examples`, если нужно.
8. **`run.bat`** — бот работает. Держи окно открытым (можно свернуть). Если бот упадёт, он перезапустится сам.

Быстро проверить нейросеть на своём тексте:
```
.venv\Scripts\python -m ozon_bot try "Наклейки очень плохого качества" --rating 5
```

## Команды в Telegram

| Команда | Что делает |
|---|---|
| `/check` | проверить прямо сейчас |
| `/status` | сколько опубликовано, сколько ждёт тебя |
| `/pending` | заново прислать всё, что ждёт решения |
| `/mode_all` · `/mode_safe` · `/mode_manual` | когда публиковать без спроса |
| `/pause` · `/resume` | остановить или продолжить автопроверку |

## Если в режиме browser бот перестал видеть отзывы

Ozon время от времени меняет кабинет. Запусти:
```
.venv\Scripts\python -m ozon_bot diagnose
```
В `data/diagnose/` появятся скриншот, HTML страницы и данные, которые кабинет загрузил. По ним правятся
`browser.selectors` в `config.yaml` (или скинь эти файлы Claude — поправит за минуту).

## Как устроено

```
ozon_bot/
  app.py          очередь задач, режимы публикации, кнопки и команды Telegram
  llm.py          промпт, запрос к локальной нейросети, разбор JSON, фильтр запрещёнки
  ozon_api.py     Seller API: /v1/review/list, /v1/review/comment/create, /v1/question/list, /v1/question/answer/create
  ozon_browser.py кабинет seller.ozon.ru через Playwright + твой Chrome
  telegram.py     Bot API на long polling, без сторонних библиотек
  storage.py      SQLite: что обработано, что ждёт кнопки
```

Тесты: `pip install pytest && python -m pytest`.
