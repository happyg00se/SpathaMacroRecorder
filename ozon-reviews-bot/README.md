# Помощник по отзывам Ozon на домашнем компьютере

Этот помощник живёт на твоём домашнем компьютере и работает круглые сутки:

- сам заходит в кабинет Ozon через Chrome;
- читает новые отзывы и вопросы;
- пишет ответы **локальной нейросетью** и публикует их.

Управлять им можно из Telegram с телефона, с макбука, откуда угодно.

**Бесплатно:**
- ни Seller API, ни подписки Premium Plus не нужно (она стоит 24 000 ₽ и ещё 2,5% оборота): бот работает в кабинете так же, как ты мышкой;
- токены нейросети тоже не тратятся: модель работает прямо на компьютере.

Нейросеть смотрит на **смысл текста, а не на звёзды**. «Пятёрка» с жалобой на качество получит извинение
и приглашение в чат. «Тройка» с похвалой получит благодарность.

```
 телефон / макбук                     домашний компьютер (24/7)
┌──────────────┐   Telegram    ┌───────────────────────────────────────────────┐
│  🔴 Отзыв…   │ ◄──────────── │  бот ──► Chrome: кабинет seller.ozon.ru       │
│  ✅ 🔄 ✏️ ⏭  │ ────────────► │   │                                           │
│  /scan       │               │   └──► Ollama: локальная нейросеть            │
│  /screen     │               └───────────────────────────────────────────────┘
└──────────────┘
```

Домашний компьютер сам ходит в Telegram, поэтому снаружи к нему подключаться не нужно. Не нужны ни белый IP, ни проброс портов, ни VPN.
Телефон и макбук просто переписываются с ботом.

## Что умеет

**Отзывы и вопросы**
- Проверяет кабинет каждые 15 минут, а по команде `/scan` — сразу.
- Определяет тон (🟢/🟡/🔴) и тему: размер, качество, доставка, «не подошло», вопрос о товаре.
- Три режима публикации, переключаются из Telegram:
  - `/mode_safe` (по умолчанию) — позитив публикуется сам, а негатив и сложные случаи приходят тебе на кнопки;
  - `/mode_all` — публикуется всё, тебе приходит отчёт;
  - `/mode_manual` — ничего не публикуется без твоей кнопки.
- Кнопки под ответом:
  - **✅ Опубликовать**;
  - **🔄 Переписать**;
  - **✏️ Свой текст** — либо указание нейросети через `?`, например `? предложи прислать фото брака`;
  - **⏭ Пропустить**.
- Сам зовёт тебя, если в отзыве угрозы, суд, риск для здоровья, подделка, спор о деньгах или нейросеть не уверена в ответе.
- Страхует от штрафов Ozon: ответ со ссылкой, телефоном, почтой или мессенджером никогда не уходит без тебя.

**Пульт Chrome с телефона.** Если Ozon разлогинил, бот пришлёт инструкцию. Войти можно прямо с телефона:

```
/login               → бот откроет вход и пришлёт снимок экрана
/click Телефон       → нажмёт на поле (пиши текст, как на снимке)
/type 9991234567     → введёт номер
/key Enter
/type 123456         → код из СМС
/scan                → проверит, что всё работает
```

`/screen` в любой момент присылает снимок того, что сейчас открыто в Chrome на домашнем компьютере.

**Помощник.** Если написать боту обычное сообщение (не команду), ответит локальная нейросеть. Она знает твой магазин и видит, какие отзывы ждут решения.
Например: «как ответить на жалобу, что клей не держит на пластике?»

## Установка на домашний компьютер (Windows)

1. **Python 3.10+** с [python.org](https://www.python.org/downloads/). При установке отметь «Add python.exe to PATH».
2. **Google Chrome**, если его ещё нет.
3. **Ollama** с [ollama.com](https://ollama.com/download) (сама запускается вместе с Windows). Потом в командной строке:
   ```
   ollama pull qwen2.5:7b
   ```
   Модель выбирай под видеокарту:
   - 8 ГБ видеопамяти — `qwen2.5:7b`;
   - 12–16 ГБ — `qwen2.5:14b`;
   - 24 ГБ и больше — `qwen2.5:32b`.
4. **Telegram-бот**: напиши [@BotFather](https://t.me/BotFather), отправь `/newbot` и скопируй токен.
5. Запусти **`setup.bat`**. Он поставит всё нужное и откроет `config.yaml`. Заполни в нём:
   - `telegram.token`;
   - раздел `shop`: название магазина, о чём он, подпись;
   - `examples`: 5–10 реальных отзывов с идеальными ответами. **От них больше всего зависит качество**: нейросеть копирует твой стиль.
6. **`login.bat`**: войди в кабинет Ozon в открывшемся окне Chrome, потом нажми Enter в консоли. Вход сохранится в отдельном профиле бота.
7. **`dry-run.bat`** покажет, что бот ответил бы на текущие отзывы, ничего не публикуя. Если ответы не нравятся, поправь `style_rules` или `examples`.
8. **`run.bat`**, затем напиши боту в Telegram `/start`. Он пришлёт твой chat id: впиши его в `telegram.allowed_chat_ids` в config.yaml.
   Закрой окно и снова запусти `run.bat`. Бот слушается только тебя, чужим он отвечает лишь их chat id.
9. **`autostart.bat`**, чтобы работало 24/7. Он включит запуск бота при входе в Windows и запретит компьютеру засыпать.
   Бонус: включи автовход в Windows, тогда после отключения света бот поднимется сам (как это сделать, `autostart.bat` подскажет).

После этого всё делается с телефона или макбука через Telegram.

## Команды

| Команда | Что делает |
|---|---|
| `/scan` | проверить отзывы и вопросы прямо сейчас |
| `/status` | сколько опубликовано, сколько ждёт тебя |
| `/pending` | заново прислать всё, что ждёт решения |
| `/mode_safe` · `/mode_all` · `/mode_manual` | когда публиковать без спроса |
| `/pause` · `/resume` | остановить или продолжить автопроверку |
| `/screen` | снимок Chrome на домашнем компьютере |
| `/login` · `/open reviews` · `/open questions` · `/open адрес` | открыть страницу |
| `/click текст` · `/type текст` · `/key Enter` | пульт: нажать, напечатать, клавиша |

Меню команд Telegram показывает прямо у поля ввода.

## Про Chrome на компьютере

- У бота свой профиль Chrome (`data/chrome-profile`), твой обычный Chrome он не трогает. Можно спокойно пользоваться браузером параллельно.
- Окно Chrome бота всё время открыто, но спрятано за краем экрана (`hide_window: true`). Если хочешь смотреть, как он работает, поставь `false`.
- Раз в 6 часов бот перезапускает Chrome, чтобы тот не копил память. Если окно закрыть руками, бот сам откроет его заново.
- Экран может гаснуть, а компьютер можно блокировать: боту это не мешает. Мешают только сон и выход из учётной записи.

## Если бот перестал видеть отзывы

Ozon время от времени меняет кабинет. Первым делом пришли боту `/screen` и посмотри, что открыто. Если там кабинет с отзывами,
а бот их не видит, останови бота и запусти:
```
.venv\Scripts\python -m ozon_bot diagnose
```
В `data/diagnose/` появятся скриншот, HTML страницы и данные, которые кабинет загрузил. По ним правятся
`browser.selectors` в `config.yaml` (или скинь эти файлы Claude, он поправит).

## Если всё-таки есть Premium Plus

Поставь в config.yaml `source: api` и заполни `ozon_api.client_id` / `api_key`: тогда бот работает через официальный API без браузера.

## Как устроено

```
ozon_bot/
  app.py          очередь задач, режимы публикации, кнопки, пульт и помощник в Telegram
  ozon_browser.py кабинет seller.ozon.ru через Playwright + Chrome: чтение, ответы, пульт
  llm.py          промпт, запрос к локальной нейросети, разбор JSON, фильтр запрещёнки
  telegram.py     Bot API на long polling, без сторонних библиотек
  storage.py      SQLite: что обработано, что ждёт кнопки
  ozon_api.py     запасной путь через Seller API (нужна подписка)
```

Проверить нейросеть на своём тексте: `.venv\Scripts\python -m ozon_bot try "Наклейки очень плохого качества" --rating 5`

Тесты: `pip install pytest && python -m pytest`.
